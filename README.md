# GARVITA'S PORTFOLIO
A playful personal portfolio for a 2nd year IT student, built to showcase major projects.
The hero is a small handheld console that you can actually play with: press a button and you can see the work.

## Features
- console hero : a handheld console with a photo on its screen.The plus button just flips it.
- Project screens : the A, B and C buttons open web, hardware and game projects on a full screen display, with each project as a card.
- Zoom into a project : picking a card zooms the camera into it and showsthe description, techstack and a link.
- About and Contact : Skills are listed along with social media handles.
- responsive and accessible : works on phones and laptops, can be used with a keyboard(arrow keys, Enter, Esc), and respects the "reduce motion" setting.

## Tech Stack
- HTML, CSS and JavaScript, with no UI framework.
- Vite for the dev server and build.
- Google Fonts(Bricolage Grotesque).
